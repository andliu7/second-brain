# second-brain

A retrieval system for your own files that costs one model call — plus the
operating layer around it and a local web console over the whole thing.

Three parts, one repo:

```
second-brain/    the engine — index, retrieve, remember. Python stdlib, no deps
├── serve.py     the console's server: localhost API over q.py / remember.py / idx.py
├── ui.html      the console: ask, remember, surprise, cortex, reindex
└── brain-ui.bat double-click to launch on Windows
OS/              the ARMS layer — memory notes, routines, the regenerated home page
```

## The engine

Most of a memory lookup needs no intelligence at all, so none is used. Stripping a
question to keywords, deciding which of thousands of sections could hold the
answer, cutting out the right paragraph — that is arithmetic, and arithmetic runs
in 50 ms. The model is invoked exactly once, at the end, with the evidence already
attached. Full design notes and honest limits: `second-brain/README.md` — including
the part where the first benchmark had to be rebuilt because it was accidentally
rigged in the system's own favour.

```
python install.py        # once, natively (PowerShell on Windows)
python q.py "why did i pick X over Y"
python remember.py "never mock the DB in integration tests" --kind gotcha
```

## The console

```
python serve.py          # → http://127.0.0.1:7432, opens automatically
```

One stdlib server, one HTML file, zero dependencies — the same rules the engine
lives by. Queries go through `q.py --json`, so the console sees exactly what a
session sees: same scorer, same confidence codes, same refusals, rendered in the
brain's own words rather than dressed up as errors. Saving a memory goes through
`remember.py`, which writes the file and its index row in one step — there is no
path through the UI that does one without the other.

The background is the index, ambient: a synapse field whose node count scales with
the section count, leaning toward your cursor, pulsing when an answer lands or a
memory is saved. `/` focuses ask, `m` focuses remember, `s` fires a random synapse.

Localhost only, with a Host-header check against DNS rebinding. It reads your
files; never expose it beyond 127.0.0.1.

## The OS layer

`OS/` is the ARMS structure — Applications, Routines, Memory, Skills — built on the
engine rather than beside it. `OS/README.md` explains the layout and why it
deliberately deviates from a portable folder-of-markdown design. The home page
(`OS/HOME.html`) is regenerated by `OS/build_home.py` from git state and status
files, never hand-edited.

## What is deliberately not committed

`index.tsv`, `brain.json`, `log.md`, `memories/`, and `OS/HOME.html` are machine
state — regenerable, machine-specific, or personal. The `.gitignore` says so.
Clone this anywhere, run `install.py`, and the brain rebuilds itself against that
machine's files.
